# Brand: the Ejadah and Sanad design language

**Authoritative.** This folder decides how Ejadah AI Labs and Sanad look, sound and are
named on every surface: the product, the website, marketing, digital marketing and
templates. Where another asset or page disagrees on how things look, this folder is correct
and the other is a defect. On **words** (the product sentence, names, status words) it
follows [ADR-0003](../adr/ADR-0003-One-Product-One-Platform.md),
[company/Branding.md](../company/Branding.md) and [product/Naming.md](../product/Naming.md). Changes need the owner's approval.

> **Status: v1.0 draft, 2026-11-21.** The rules and tokens are ready to use. The SVG logos in
> [logos/](logos/) are **drafts** pending owner approval; until then the existing PNGs
> (`ejadah-website/public/logo.png`, `Sanad/media/Sanad.png`) stay in use.

**See it:** [the brand page](https://claude.ai/artifact/HehuGAj4663jVYKPAx5mC2) (swatches,
logos, type, voice, templates) · [the slide master](https://claude.ai/artifact/PNkkcRSB4pQtT1D2mgJxQp)
(six layouts). Both are private until the owner shares them from the page's Share menu.

## The idea in one line

**A chain of evidence you can follow and regenerate.**

Both marks already draw it: nodes joined by edges (the Ejadah E-mark) and two links of one
chain with a checked node (Sanad). Every visual we make is built from three things:
**node · edge · check**. If a layout, diagram or illustration can't be explained in those
terms, it probably doesn't belong.

## The files

| Path | What it is |
|---|---|
| [tokens/tokens.json](tokens/tokens.json) | **The source of truth** for colour, type and shape |
| [tokens/tokens.css](tokens/tokens.css) | Generated CSS variables, dark and light. Never edit by hand |
| `tokens/build-tokens.mjs` | Regenerates `tokens.css`; `--check` fails if it's stale |
| `tokens/check-contrast.mjs` | Proves every allowed colour pair meets WCAG, and that forbidden pairs fail |
| [logos/](logos/) | SVG marks, generated by `logos/make-logos.py` |
| [templates/](templates/) | Social, banner, one-pager and email-signature templates |
| `page/` | Source of the brand page: `python3 -I page/build-page.py brand <out.html> page/brand-page.src.html` |

```bash
node brand/tokens/check-contrast.mjs      # must print "checks passed"
node brand/tokens/build-tokens.mjs --check
```
